# 04 — Bundle Generation

`GenerateBundle` writes the application Secret and ConfigMap into the bundle directory. These are standalone Kubernetes manifests applied directly to the cluster — not managed by the Orkestra operator's selector.

## What gets generated

```
.orkestra/bundle/
  app-secrets.yaml    ← Kubernetes Secret  (base64-encoded values)
  app-config.yaml     ← Kubernetes ConfigMap  (plaintext values)
```

Only files for non-empty variable sets are written: if there are no secrets, `app-secrets.yaml` is not created; if there are no config vars, `app-config.yaml` is not created.

## The Secret

```yaml
# .orkestra/bundle/app-secrets.yaml
# Generated by ork deploy — DO NOT COMMIT THIS FILE
# Add .orkestra/bundle/ to .gitignore

apiVersion: v1
kind: Secret
metadata:
  name: my-app-secrets
  namespace: my-app-ns
type: Opaque
data:
  DATABASE_URL: cG9zdGdyZXM6Ly8...   # base64
  JWT_SECRET: YWJjMTIzeHl6...
```

Values are base64-encoded using `encoding/base64` standard encoding. The name is `<app>-secrets` and the namespace is `<app>-ns` — matching what the generated Katalog references in `envFrom`.

## The ConfigMap

```yaml
# .orkestra/bundle/app-config.yaml
# Generated by ork deploy — DO NOT COMMIT THIS FILE

apiVersion: v1
kind: ConfigMap
metadata:
  name: my-app-config
  namespace: my-app-ns
data:
  PORT: "8080"
  LOG_LEVEL: "info"
```

Values are written as quoted strings. The name is `<app>-config`.

## Security model

`.orkestra/bundle/` is added to `.gitignore` by `ork doctor init`. Generated secret files never enter source control.

`ork deploy` regenerates the bundle from the local `.env` on every run. This means:
- Adding a variable to `.env` and re-running `ork deploy` applies it to the cluster.
- Removing a variable and re-running `ork deploy` removes it from the Secret/ConfigMap.
- The cluster's live Secret always reflects the local `.env` after the most recent deploy.

For production secret rotation without re-deploying: edit the Kubernetes Secret directly. The operator does not touch secrets it did not create in the current reconcile cycle.

## Usage

```go
info, _ := doctor.Detect(".")

err := doctor.GenerateBundle(
    info.AppName,
    info.AppName+"-ns",
    info.Secrets,
    info.Config,
    ".orkestra/bundle",
)
```

## File permissions

`app-secrets.yaml` is written with mode `0600` — readable only by the current user. `app-config.yaml` uses `0644`.
