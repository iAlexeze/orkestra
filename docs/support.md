# Support

Orkestra is an open‑source project maintained by a growing community of contributors.  
This page explains how to get help, report issues, and request new features.

---

## Community Support

> !!! tip 
> Community support is the fastest way to get help for general questions, troubleshooting, and best practices.

You can reach the Orkestra community through:

- **GitHub Discussions** — ask questions, share ideas, get help from maintainers  
- **GitHub Issues** — report bugs or request enhancements  
- **Community Slack/Discord** (if you choose to create one later)  
- **Documentation** — the official docs cover installation, concepts, and examples  

Community support is best for:

- “How do I…?” questions  
- Troubleshooting unexpected behavior  
- Understanding Orkestra concepts  
- Sharing feedback or suggestions  

---

## Reporting Bugs

If you believe you’ve found a bug, please open a GitHub issue with:

- A clear description of the problem  
- Steps to reproduce  
- Expected vs actual behavior  
- Relevant logs (Orkestra runtime logs are extremely helpful)  
- Your Orkestra version  
- Kubernetes version  

> !!! note
> Issues with incomplete information may take longer to diagnose.

---

## Requesting Features

Feature requests are welcome.  
When opening a feature request, include:

- The problem you’re trying to solve  
- Why the feature is valuable  
- Any alternatives you’ve considered  
- Example use cases  

This helps maintainers understand the context and prioritize effectively.

---

## Security Issues

> !!! warning
> Do **not** open public GitHub issues for security vulnerabilities.

If you discover a security issue:

- Email the Orkestra maintainers privately  
- Provide steps to reproduce  
- Include any logs or details that help assess severity  

Responsible disclosure keeps the community safe.

## Before Opening an Issue

Please check:

- The **FAQ**  
- The **Troubleshooting** section  
- Existing GitHub issues  
- The **katalog** and **health** endpoints  
- Orkestra runtime logs  

Many common questions are already answered.
