# Registry‑Powered Operators

The Orkestra Registry provides reusable implementations for:

- Deployments  
- Services  
- Secrets  
- ConfigMaps  
- Namespace provisioning  
- Multi‑namespace secret distribution  
- Drift correction  
- Finalizers  
- Status helpers  

!!! note
    Templates and hooks call into the Registry — giving you production‑grade behavior without writing boilerplate.
