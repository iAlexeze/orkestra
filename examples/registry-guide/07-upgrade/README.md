# 07 — Upgrade

Two kinds of change. Two different strategies.

| | |
|---|---|
| [implementation-evolution/](implementation-evolution/README.md) | A motif version adds new inputs. The API is unchanged. Teams upgrade independently on their own schedule. |
| [api-evolution/](api-evolution/README.md) | The CRD field layout changes. Existing CRs need a conversion path. |

Start with `implementation-evolution/` if you are coming from [06-pattern-zoo](../06-pattern-zoo/README.md).

Jump to `api-evolution/` if you are here specifically to understand CRD field migration — it is self-contained.
