# Orkestra Control Center

The Orkestra Control Center provides a unified observability layer for one or more Orkestra runtimes. It gives platform teams and developers a complete view of Katalogs, CRDs, worker pools, queue pressure, dependency health, enriched configuration, and runtime status.

The Control Center requires no instrumentation or configuration. All data is derived directly from the Orkestra runtime APIs.

## Key Capabilities

- Multi‑runtime monitoring from a single interface  
- Control Center (global view) and Control Panel (per‑Katalog view)  
- CRD‑level detail including workers, queue depth, reconcile metrics, and RBAC  
- Config vs Enriched views for both Katalogs and CRDs  
- Dependency visualization with failure tracing  
- Built‑in authentication (username/password + signed session cookie)  
- Runtime management UI (add, update, delete runtimes)  
- Online/offline runtime health detection  
- Zero configuration required  

## Documentation Structure

- **Getting Started** — launch the Control Center locally  
- **Deploying** — run the Control Center in Kubernetes (YAML or Helm)  
- **Architecture** — understand the Control Center and Control Panel  
- **Runtime Management** — add/update/delete runtimes from the UI
